# Maison Harman · back-office demo

A clickable demo of the shop's private dashboard (orders, perfumes, stock, counter sale, prices, money, reports, customers), in Arabic and English.

- Everything runs in your browser: the sample data is made up and saved only on your device. "Reset demo data" in Settings starts over.
- The login page is a placeholder; the real version will have a password, and only the owner will have access.
- Meta events are never sent from the demo.
